How to read this

  • One bar = one API request. Width = all input tokens the model read.
  • The thin strip under each bar shows the cache: read (cheap, dark), written (extra cost, mid), not cached (full price, bright).
  • Bar totals are exact (from the log). The split into colours is an estimate (≈).
  • Faint vertical lines mark every 50k or 100k tokens.
  • Click a segment to see what is inside. Click a request label for its numbers.
