# SNAKE-07: Pause

Size: S

## Story

As a player, I want to pause the game, so that I can stop for a moment and continue later.

## Acceptance criteria

1. Given a game runs, when I press P, then the snake stops and the text "Paused" shows.
2. Given the game is paused, when I press P again, then the snake moves again from the same position.
3. Given the game is paused, when I press an arrow key, then the direction does not change.
4. Given "Game over" shows, when I press P, then nothing happens.
