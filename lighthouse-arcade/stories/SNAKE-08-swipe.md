# SNAKE-08: Swipe controls

Size: M

## Story

As a player on a phone or a tablet, I want to steer the snake with a swipe, so that I can play without a keyboard.

## Acceptance criteria

1. Given a game runs on a touch screen, when I swipe up, down, left or right on the game area, then the snake turns in that direction.
2. Given a swipe is shorter than 30 pixels, when I lift my finger, then the snake does not turn.
3. Given "Game over" shows, when I tap the game area, then a new game starts.
4. Given I swipe on the game area, when the page could scroll, then the page does not scroll.
