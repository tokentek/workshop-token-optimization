# SNAKE-05: Start a new game

Size: S

## Story

As a player, I want to start a new game with one key, so that I can play again fast.

## Acceptance criteria

1. Given "Game over" shows, when I press Space, then a new game starts.
2. Given "Game over" shows, when I press Enter, then a new game starts.
3. Given a new game starts, when the first tick comes, then the score is 0, the snake has 3 segments and the speed is the start speed.
4. Given a new game starts, when I look at the screen, then the high score from the last game still shows.
